# رَشّة | RASHA

متجر عربي RTL للعطور الأصلية وعطور التركيب، موجّه إلى قطاع غزة. التقنية المعتمدة: Next.js App Router وTypeScript وTailwind CSS وFramer Motion، مع Supabase للبيانات وتخزين الصور في Cloudflare R2. لا توجد بوابة دفع إلكتروني؛ إنشاء الطلب يتم على الخادم ثم يُعرض للعميل رابط واتساب لإكمال التواصل.

## التشغيل المحلي

1. استخدم Node.js 24 وpnpm.
2. انسخ `.env.example` إلى `.env.local` وأدخل بيانات بيئة اختبار تملك صلاحية استخدامها.
3. ثبّت الاعتماديات عبر `pnpm install`.
4. شغّل بيئة التطوير عبر `pnpm dev`.
5. نفّذ `pnpm typecheck` و`pnpm test` قبل الدمج.

هذا الإعداد المحلي لا ينشئ مشروع Supabase أو حاوية R2 ولا ينشر شيئاً. أي موارد سحابية أو نشر أو كلفة تحتاج مراجعة مستقلة من كرم قبل تنفيذها.

## عقود البيانات

- تستخدم استجابات JSON أسماء camelCase.
- تُرسل الأسعار والإجماليات كسلاسل عشرية لحفظ دقة PostgreSQL `NUMERIC`، والعملة `ILS`.
- تستخدم قوائم المنتجات `items` و`pagination: { page, pageSize, total, hasMore }`.
- تُحسب `facets.brands` و`facets.scentFamilies` على كامل النتائج المنشورة المطابقة للفلاتر، لا على الصفحة الظاهرة فقط.
- يجمع `/api/storefront/home` إعداد Hero وشريط العرض والبانرات والأقسام المختارة والتقييمات المعتمدة فقط.
- يعرض `/api/storefront/settings` اسم المتجر وواتساب ومعلومات التواصل والسياسات؛ قالب الطلب وحد المخزون يبقيان في استجابة الإدارة فقط.
- تُسجّل التقييمات عبر `/api/reviews` بحالة `pending`، ولا تظهر للزوار قبل موافقة المدير.
- أنواع لوحة الإدارة موجودة في `src/lib/contracts/admin.ts`، وجميع مساراتها تتطلب جلسة مدير فعالة.
- يرسل المتصفح معرفات المتغيرات والكميات فقط عند إنشاء الطلب؛ يعيد الخادم قراءة السعر والمخزون من قاعدة البيانات.
- تحفظ عناصر الطلب لقطات الاسم والنوع والحجم والسعر والكمية عند الإنشاء.
- يبدأ الطلب بالحالة `whatsapp_initiated`. لا يُحجز المخزون ولا يُخصم عند إنشاء الطلب أو فتح واتساب.
- يخصم المخزون عند تأكيد المدير، ويعاد مرة واحدة عند إلغاء طلب سبق خصم مخزونه، بعملية ذرية تسجّل حركة المخزون.
- تظل تكلفة التوصيل `null` عند إنشاء الطلب؛ يتفق عليها العميل والمتجر عبر واتساب.

العقود والتحقق المبدئي من شكل طلب إنشاء الطلب في `src/lib/contracts/storefront.ts`. التحقق في الواجهة ليس حاجزاً أمنياً؛ يجب على كل مسار خادمي إعادة التحقق وتطبيق التفويض.

## البيئة والأسرار

يحتوي `.env.example` على أسماء المتغيرات، مع رقم واتساب المتجر الوارد في المواصفة كقيمة افتراضية؛ بقية مفاتيح الخدمة وبيانات R2 فارغة وتبقى على الخادم، ولا تُستخدم بادئة `NEXT_PUBLIC_` لأي سر.
